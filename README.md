# xiaomi-eas-import-adapter（小爱伴侣教务导入适配）

将教务系统（EAS，Educational Administration System）的课表数据适配导入「小爱伴侣」开发者扩展的项目。

> ⚠️ 本文档的「隐私与配置」部分为**重点**。完整使用文档（扩展安装、课表解析规则、与小爱伴侣对接说明等）仍在补充中。

---

## ⚠️ 隐私与配置说明（使用前必读）

### 1. 已从仓库移除的隐私内容
- `.workbuddy/` 工作日志（含本机路径与账号信息），已从提交历史移除并强制推送清理。

> 本项目**无需 `private_config.json`**：运行时不依赖任何密钥 / 登录态文件（教务登录态由「小爱伴侣」的教务 WebView 在运行时获取）。这是统一的「单一隐私文件」约定的例外——无需创建该文件。

### 2. 教务账号的处理方式
- 本项目**不存储任何教务账号密码**：登录态由「小爱伴侣」的教务 WebView 在运行时获取，`provider.js` / `parser.js` 仅做课表解析，**代码中无硬编码凭据**。
- 请勿将包含个人课表、学号等信息的导出文件提交到仓库。

### 3. 安全建议（通用）
- 含有 token、Cookie、私钥的文件加入 `.gitignore`，绝不要 `git add`。
- 推送前用 `git status` 确认无敏感文件被跟踪。
- 若曾把密钥误提交，立即作废对应凭证，并改写历史后强制推送。
